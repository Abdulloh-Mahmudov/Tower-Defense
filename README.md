Tower Defense Game

A 3D Tower Defense game built with Unity and C#.
The player must strategically place turrets to defend against waves of enemies moving through a navigation path.

This project demonstrates core gameplay systems commonly used in tower defense games such as enemy pathfinding, wave management, turret targeting, and UI systems.

Gameplay Overview

In this game, enemies spawn in waves and follow a predefined path toward the player's base. The player must build and manage turrets to destroy the enemies before they reach the objective.

Each wave becomes progressively more difficult, requiring the player to carefully place defenses and manage resources.
